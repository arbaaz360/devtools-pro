# DU-09 — Backslash Escaper/Unescaper

`text.backslash` (one of three independent operations in the `text.escaping` package) escapes and unescapes a self-contained backslash grammar — `\\ \n \r \t \b \f \v \0 \" \' \xHH \uHHHH \u{H...}` — that the README states explicitly is "independent of HTML and of JSON literals," with every ambiguous or unsupported escape spelled out as its own rejection code rather than guessed. This is the strongest-fitting card audited in this packet: every Required, UX-backend and Acceptance item checked came back `met`.
