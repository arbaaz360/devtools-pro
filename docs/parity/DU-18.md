# DU-18 — JSON to YAML (`convert.yaml`, operation `convert.json-yaml`)

`convert.json-yaml` parses its input with `plugins/json`'s own tokenizer
(so "valid JSON" and "exact number" mean the same thing across both
packages) and emits block-style YAML with the minimum quoting needed for
every string and key to round-trip exactly, multiline strings as literal
block scalars with the correct chomping indicator, and JSON number lexemes
copied verbatim rather than routed through `Number`. Every requirement in
this card is met; the package's README documents a round-trip test against
`plugins/json`'s own minifier as the oracle, and this audit reproduced the
scalar-quoting and multiline behavior directly.

| # | What the card requires | What the tool does | Verdict | Evidence |
|---|---|---|---|---|
| 1 | JSON document to YAML | Parses JSON via `plugins/json`'s `scanDocument`, emits block-style YAML | met | `--input 'input={"a":1}'` → `{"operation":"convert.json-yaml","keys":1,...}`; text output `a: 1` |
| 2 | Appropriate scalar quoting | A string (or key) is quoted exactly when a plain reading would parse as something else, start a structural token, or contain `": "`/`" #"`/a line break | met | scratchpad run on `{"c":"1.2300","d":null,"e":"yes","f":"","g":"  leading"}` → `c: "1.2300"` (would parse as a number unquoted), `d: null`, `e: yes` (unquoted — "yes" is not a YAML 1.2 core-schema boolean, so no quoting is needed for its own round trip), `f: ""` (empty string), `g: "  leading"` (leading whitespace forces quoting) |
| 3 | UX: JSON input, YAML output, clipboard/sample/clear/copy | Ports declare `language: "json"` in / `language: "yaml"` out; buttons are shell components | n/a (shell) | `manifest.json` `inputs[0]`/`outputs[0]` |

| 5 | Null/bool/number/string distinctions | Each JSON type maps to its literal YAML form; strings needing it are quoted per row 2 | met | scratchpad run above: `d: null` (bare), `b: 123` (bare number), `e: yes` (bare string) all distinct and unambiguous on the way back |

| 14 | Empty collections | `{}`/`[]` for empty object/array | met | `plugins/yaml/README.md` §"JSON → YAML" ("empty collections as `{}`/`[]`") |

## Not covered

The JSON/YAML editor panes, clipboard/sample/clear/copy buttons, and syntax
highlighting are shell/presentation concerns outside a headless audit. The
package's one disclosed limitation — an embedded literal `\r` not followed
by `\n` inside a string is indistinguishable, on the way back, from a CRLF
line ending inside a literal block scalar's body — is a known, documented
edge case rather than something the card names as an acceptance scenario.
