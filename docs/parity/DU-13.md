# DU-13 HTML Beautifier/Minifier

The `format.html` plugin provides a tolerant HTML formatter that beautifies and minifies HTML code, preserving incomplete markup without failing. It meets most of the card's processing requirements, but completely lacks support for formatting embedded CSS/JS.

| # | What the card requires | What the tool does | Verdict | Evidence |

Closing gaps:
- To close the `missing` embedded CSS/JS gap, the plugin needs to invoke `format.css` and `format.javascript` for the contents of `<style>` and `<script>` tags respectively, or the SDK must provide a way for plugins to delegate formatting of sub-regions.

## Not covered

Presentation-specific requirements (editable source layout, workspace clipboard/sample buttons) are not verified headlessly.
