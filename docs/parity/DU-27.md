# DU-27 — String Case Converter (`text.case`)

`text.case` converts identifier-style text line by line into one of six
target cases, splitting words on case humps, digit boundaries and
punctuation, and optionally keeps a configurable list of acronyms
(`ID,API,DB,URL,HTTP` by default) in their all-caps form. It matches the
card closely: every named case target works, word-splitting handles the
documented boundary rules including digits and combining-mark Unicode, and
line/blank-line/CRLF structure is preserved byte for byte. The one gap is
that acronym detection is case-insensitive and whole-word only, so it
cannot special-case a name that collides with an acronym only by casing.

| # | What the card requires | What the tool does | Verdict | Evidence |
|---|---|---|---|---|
| 1 | `camelCase` target | `target: "camel"` lowercases the first word, capitalizes the rest | met | `--options '{"target":"camel"}' --input "input=v2Api"` → `{"text":"v2API"}` (acronym `API` recognized after the digit split) |
| 2 | `snake_case` target | `target: "snake"`, words joined with `_`, all lowercase | met | `--options '{"target":"snake"}' --input "input=userID_loader"` → `{"text":"user_id_loader","acronymsApplied":1}` |
| 3 | `PascalCase` target | `target: "pascal"`, every word capitalized, no separator | met | `--options '{"target":"pascal"}' --input "input=café_naïve"` → `{"text":"CaféNaïve"}` |
| 4 | `kebab-case` target | `target: "kebab"`, words joined with `-`, all lowercase | met | `--options '{"target":"kebab"}' --input "input=foo.bar-baz!qux"` → `{"text":"foo-bar-baz-qux"}` |

| 6 | `CONSTANT_CASE` target | `target: "constant"`, words joined with `_`, all uppercase | met | same vectors fixture; `--options '{"target":"constant"}'` idempotence is asserted for every vector by the "vectors convert correctly and are idempotent" test |

| 13 | Preserve line-oriented multiple-name workflow | Input is split on `\r\n`/`\n`, each line converted independently, endings and blank lines re-emitted unchanged | met | `--input "input=$(printf '   \n\n  x_y  \n')" --options '{"target":"camel"}'` → `{"lines":3,"text":"   \n\n  xY  "}` |
| 14 | Acronym/word boundaries | Splits on a lower→upper hump and on an uppercase run followed by a capitalized word (`HTTPServerAPI` → `HTTP`, `Server`, `API`) | met | `--options '{"target":"pascal"}' --input "input=HTTPServerAPI"` → `{"text":"HTTPServerAPI","acronymsApplied":2}` (unchanged because `HTTP` and `API` are both already-correct acronym casing in Pascal) |
| 15 | Digits | Splits at every letter↔digit boundary (`v2Api` → `v`, `2`, `Api`) | met | `--options '{"target":"camel"}' --input "input=v2Api"` → `{"text":"v2API"}` (see row 1) |

| 17 | Punctuation | Whitespace, `_`, `-` and generic punctuation all split words | met | `--options '{"target":"snake"}' --input "input=foo.bar-baz!qux"` → `{"text":"foo_bar_baz_qux"}` |

| 19 | Each target case | All six `TARGETS` are covered by the fixture-driven idempotence loop | met | `plugins/string-case/test.mjs` "vectors convert correctly and are idempotent" iterates `TARGETS` for every fixture vector; 5/5 tests pass |
| 20 | Acronym toggle | `preserve-acronyms: false` treats acronym words as ordinary words | met | `--options '{"target":"snake","preserve-acronyms":false}' --input "input=userId"` → `{"text":"user_id","acronymsApplied":0}` (compare row 2, which applies the acronym) |
